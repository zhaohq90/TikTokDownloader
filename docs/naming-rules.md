# 命名规则

## 用户作品目录命名

目录命名由下载模式决定，格式固定，不可通过配置文件修改。

| 下载模式 | 目录格式 | 示例 |
|----------|----------|------|
| 发布作品 | `UID{uid}_{昵称}_发布作品` | `UID97741555095_云姑娘_发布作品` |
| 喜欢作品 | `UID{uid}_{昵称}_喜欢作品` | `UID97741555095_云姑娘_喜欢作品` |
| 合集作品 | `MID{合集ID}_{合集名}_合集作品` | `MID7123456789_旅行合集_合集作品` |
| 收藏作品 | `UID{uid}_{昵称}_收藏作品` | `UID97741555095_云姑娘_收藏作品` |
| 收藏夹作品 | `CID{收藏夹ID}_{收藏夹名}_收藏夹作品` | `CID7123456789_我的收藏_收藏夹作品` |
| 单作品详情 | 使用 `folder_name` 配置项 | `Download` |

其他固定目录：`Music/`（音乐）、`Live/`（直播）。

## 作品文件命名

文件名由 `settings.json` 中的以下配置项控制：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `name_format` | `create_time type nickname desc` | 文件名组成字段，空格分隔 |
| `split` | `-` | 字段间的分隔符 |
| `date_format` | `%Y-%m-%d %H:%M:%S` | 时间的格式化模板 |
| `name_length` | `128` | 文件名最大长度（字节） |
| `desc_length` | `64` | 描述字段截断长度 |
| `folder_mode` | `false` | 是否为每个作品创建独立子文件夹 |

### name_format 支持的变量

| 变量 | 含义 | 示例值 |
|------|------|--------|
| `id` | 作品ID（纯数字，全局唯一） | `7646403064845207177` |
| `create_time` | 发布时间（格式由 `date_format` 控制） | `2026-06-01_20.29.08` |
| `type` | 作品类型 | `视频` / `图集` / `实况` |
| `nickname` | 作者昵称 | `云姑娘` |
| `desc` | 作品描述（截断至 `desc_length`） | `梨形身材微胖日常#创作灵感` |
| `uid` | 作者UID | `97741555095` |
| `mark` | 账号备注名（settings.json 中 mark 字段） | `拿拿不了铁` |

### date_format 支持的占位符

使用 Python strftime 格式，常用占位符：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `%Y` | 四位年份 | `2026` |
| `%m` | 两位月份 | `06` |
| `%d` | 两位日期 | `11` |
| `%H` | 24小时制小时 | `20` |
| `%M` | 分钟 | `29` |
| `%S` | 秒 | `08` |

### 文件名生成规则

1. 按 `name_format` 中的字段顺序，用 `split` 连接各字段值
2. 过滤非法字符：`/ \ | < > " ? : *` 及控制字符（根据操作系统）
3. 去除 Emoji 和首尾空白/点号
4. 截断至 `name_length` 指定的字节长度
5. 图集多图追加 `_N` 序号（N 从 1 开始）
6. 追加扩展名：`.mp4`（视频）、`.jpeg`（封面/图集）

### 命名示例

配置 `name_format: "create_time id type"`、`split: "_"`、`date_format: "%Y-%m-%d_%H.%M.%S"` 时：

```
2026-06-01_20.29.08_7646403064845207177_视频.mp4
2026-06-01_20.29.08_7646403064845207177_视频.jpeg
2025-03-25_12.35.58_7485601156392160562_图集_1.jpeg
2025-03-25_12.35.58_7485601156392160562_图集_2.jpeg
2025-03-25_12.35.58_7485601156392160562_图集_3.jpeg
```

配置 `name_format: "create_time type nickname desc"`、`split: "-"`、`date_format: "%Y-%m-%d %H.%M.%S"` 时：

```
2026-06-01 20.29.08-视频-云姑娘-六一在爸妈身边当小孩.mp4
2025-03-25 12.35.58-图集-@33不吃菜-心平可愈三千疾。_1.jpeg
```
