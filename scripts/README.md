# 独立脚本工具

## rename_files.py — 批量重命名作品文件

将作品目录中的文件从旧命名格式批量转换为新的命名格式。

### 功能

- 读取 `settings.json` 中的 `date_format`、`split` 配置，按新规则生成文件名
- 从 `DetailData.db` 数据库中查找作品ID，匹配到的文件名包含 ID
- 数据库中无记录的文件，文件名中不含 ID，仅用时间+类型命名
- 图集多图文件保留 `_1`、`_2`、`_3` 序号后缀
- 已是新格式命名的文件自动跳过
- 通过 UID 匹配数据库表名，兼容目录名与表名因特殊字符不一致的情况
- 每次运行生成日志文件，记录修改前后的文件名
- 支持跳过指定目录（如已手动处理过的账号）

### 旧格式 → 新格式

```
旧: 2023-05-06 19.18.13-视频-云姑娘-描述内容.mp4
新: 2023-05-06_19.18.13_7646403064845207177_视频.mp4  (有ID)

旧: 2023-05-06 19.18.13-视频-云姑娘-描述内容.mp4
新: 2023-05-06_19.18.13_视频.mp4                      (无ID)

旧: 2023-05-06 19.18.13-图集-云姑娘-描述内容_1.jpeg
新: 2023-05-06_19.18.13_7646403064845207177_图集_1.jpeg (图集保留序号)
```

### 使用方式

```bash
# 预览模式：只输出变更计划，不实际重命名
python3 scripts/rename_files.py

# 确认无误后，执行重命名
python3 scripts/rename_files.py --execute
```

### 日志文件

每次运行在 `Volume/` 目录下生成 `rename_log_{时间戳}.txt`，内容格式：

```
Rename Log - 2026-06-11 20:35:00
date_format: %Y-%m-%d_%H.%M.%S
split: _
mode: DRY RUN
================================================================================

DIR:  UID97741555095_云姑娘_发布作品
OLD:  2023-05-06 19.18.13-视频-云姑娘-描述.mp4
NEW:  2023-05-06_19.18.13_7646403064845207177_视频.mp4
NOTE: ID=7646403064845207177

DIR:  UID97741555095_云姑娘_发布作品
OLD:  2022-10-19 15.33.59-视频-云姑娘-描述.mp4
NEW:  2022-10-19_15.33.59_视频.mp4
NOTE: NO_ID
```

### 跳过目录

在脚本中修改 `SKIP_DIRS` 集合可跳过指定目录，默认跳过已按新规则处理过的账号：

```python
SKIP_DIRS = {"UID4253382337112871_喜喜_发布作品"}
```

### 输出状态说明

| 状态 | 含义 |
|------|------|
| `ID=xxx` | 匹配到数据库记录，文件名包含作品ID |
| `NO_ID` | 数据库中无记录，文件名不含作品ID |
| `SKIP` | 文件名无法解析，跳过 |
| `CONFLICT` | 目标文件名已存在或同批次重名，跳过 |
| （无标记） | 已是新格式命名，自动跳过 |
